# 01 - Project Brief

## Project Name

AI-Assisted Financial Intelligence Pipeline

## Project Type

Portfolio-grade analytics engineering project.

## Project Objective

Build an end-to-end workflow that transforms messy financial documents or semi-structured financial inputs into validated financial metrics, SQL-based KPI models, dashboard-ready datasets, and executive summaries.

## Target Audience

This project is designed to impress or inform:

- Data analyst hiring managers
- Analytics engineering reviewers
- Finance analytics teams
- BI developers
- CFO / FP&A stakeholders
- Technical recruiters evaluating portfolio quality

## Core Value Proposition

Most beginner analytics projects start from a clean CSV file. This project starts from the real-world assumption that business data is messy, fragmented, semi-structured, and often trapped inside documents.

The value is not only in the final dashboard. The value is in the full analytical chain:

```text
messy source → structured data → validated metrics → SQL model → dashboard table → executive insight
```

## Business Questions

The project should answer:

1. Which company has the highest revenue growth?
2. Which company has the strongest profitability?
3. Which company has the highest debt risk?
4. Which company has the strongest cash position?
5. Are risk signals increasing over time?
6. Can financial document data be transformed into reliable analytics outputs?

## MVP Deliverables

- Synthetic financial metrics CSV
- SQLite database schema
- Data loading script
- SQL KPI queries
- Dashboard-ready mart table
- Executive summary Markdown report
- Validation report
- Dashboard specification
- README and documentation

## Out of Scope for MVP

The following are intentionally not part of the MVP:

- Full production orchestration
- Cloud deployment
- Vector database
- Multi-user web app
- Real-time financial API ingestion
- Automated investment recommendation
- Complex machine learning model
- Full OCR pipeline for scanned documents

These can be added later only after the core analytics workflow works.

## Success Definition

The MVP is successful if a reviewer can:

1. Understand the business problem in less than 2 minutes.
2. Run or inspect the data pipeline.
3. See clear SQL metric logic.
4. Understand the data model.
5. Open dashboard-ready outputs.
6. Read a meaningful executive summary.
7. Trust the validation process.

## Positioning Statement

This is not an AI gimmick. It is an analytics engineering workflow enhanced by AI-assisted document processing and executive reporting.
